# Q Collage

[English](./README.md)

순수 클라이언트 기반 이미지 콜라주 생성기입니다. 여러 장의 사진을 드래그 앤 드롭하여 자동으로 격자 형태로 배치할 수 있습니다. 열과 행의 수, 비율, 간격(Gutter)을 자유롭게 조절하고 고해상도 PNG 또는 JPG로 저장하세요. 서버 업로드 없이 브라우저에서 최대 8192px 너비의 고해상도 작업을 즉시 처리합니다.

# Our Philosophy
IDDQD Internet은 별도의 DB나 회원가입 없이, 순수 HTML/JS만으로 브라우저에서 즉시 실행되는 도구를 개발합니다. AI 기능을 제공할 때도 데이터 상태를 유지하지 않으며(stateless), 어떠한 기록도 남기지 않는 원칙을 고수합니다.

# Features
- **드래그 앤 드롭**: 여러 장의 이미지를 한 번에 쉽게 추가할 수 있습니다.
- **그리드 커스터마이징**: 1행 1열부터 50행 50열까지 자유롭게 레이아웃을 조절할 수 있습니다.
- **비율 제어**: 1:1, 16:9, 4:3 둥 다양한 가로세로 비율 프리셋을 지원합니다.
- **간격(Gutter) 조절**: 이미지 사이의 여백을 픽셀 단위로 정밀하게 조정합니다.
- **고해상도 출력**: 최대 가로 8192px 해상도의 이미지를 생성하고 다운로드할 수 있습니다.
- **프라이버시 보호**: 모든 작업은 브라우저 내부에서만 이루어지며, 이미지는 서버로 전송되지 않습니다.
- **포맷 옵션**: PNG 및 JPG (품질 80/100) 다운로드를 지원합니다.
- **셔플**: 버튼 하나로 이미지 배치를 무작위로 섞을 수 있습니다.

# Usage
1. 웹 브라우저에서 앱을 엽니다.
2. 이미지를 드롭존에 드래그하거나 파일 선택 버튼으로 불러옵니다.
3. 왼쪽 패널에서 설정을 조절합니다:
   - **Col/Row**: 그리드의 열과 행 개수 설정
   - **비율**: 전체 캔버스의 가로세로 비율
   - **Gutter**: 이미지 사이의 간격
   - **전체 크기**: 출력될 이미지의 가로 해상도
4. **Shuffle** 버튼을 눌러 이미지 순서를 변경해 봅니다.
5. **Download** 버튼을 눌러 결과물을 저장합니다.

# Tech Stack
- **Core**: HTML5, CSS3, JavaScript (ES6+)
- **Libraries**: jQuery 3.7.1, Bootstrap 5.3.3
- **Rendering**: HTML5 Canvas API를 사용한 실시간 합성 및 내보내기
